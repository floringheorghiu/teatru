1 · StateGraph & compile()

        
A graph is a typed StateGraph(GraphState): you register nodes (add_node(name, fn)) and edges, then compile(checkpointer) turns the declaration into a runnable. The compiled object is immutable — executing it never rewrites the topology.

      
2 · Nodes are plain functions

        
Each node receives the full state and returns a partial dict of updates. Never mutate the incoming state — the framework merges your return value into it. n_preflight returns only reachable / aborted / timings.

      
3 · Conditional edges = routing functions

        
add_conditional_edges("preflight", r_after_preflight, ["abort","plan"]) — the function reads state and returns the next node's name. Abort-on-systemic-failure / degrade-on-one-dead-venue becomes visible topology instead of buried if-statements.

      
4 · Send() — the map step

        
A conditional edge may return list[Send] instead of a node name. Each Send("extract_one", task) spawns an instance of the node with its own private payload (ExtractTask), not the whole state. That is how 11 snapshots fan out into 11 parallel workers.

      
5 · Reducers — the reduce step

        
Concurrent workers all write to results. The field is declared Annotated[list, operator.add], so the framework concatenates their outputs instead of raising InvalidUpdateError: Can receive only one value per step. This is the #1 fan-out gotcha.

      
6 · Supersteps & the implicit barrier

        
Execution proceeds in supersteps (Pregel-style): all nodes scheduled in step N finish before step N+1 starts. That is why verify — with one edge from extract_one — automatically waits for all 11 workers. No barrier code exists; the join is free.

      
7 · Checkpointer & thread_id

        
SqliteSaver persists state after every superstep, keyed by thread_id. Re-invoke with the same id and execution resumes from the last checkpoint — a crash in render doesn't re-fetch 11 sites or re-pay for extraction. teatre_graph_checkpoints.db holds it here.

      
8 · The design ratio: 1 model node

        
Only the fallback rung of extract_one can call a model — and even that runs deterministic parsers first (T.deterministic_rows). verify is a pure function. LangGraph adds orchestration (state, fan-out, checkpoints, tracing), not autonomy. A model cannot be asked to promise it followed a procedure; the graph structure makes the procedure the only path.

      
9 · invoke() and recursion_limit

        
graph.invoke(initial_state, {"configurable": {"thread_id": ...}, "recursion_limit": 200}) drives the run to END. The limit counts supersteps — fan-out of 11 workers still costs little because parallel Sends share one superstep.
